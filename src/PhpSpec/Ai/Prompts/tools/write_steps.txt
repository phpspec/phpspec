Appends the step definitions for a feature's undefined steps to a steps file:
steps.php in the steps directory, or the file steps_file names (web for
web.steps.php), never one file per feature. phpspec parses the feature and owns the
step patterns; give it the feature's project-relative path. Scaffolding only: when
the steps already exist and the ask is about their bodies, edit the steps file with
propose_edit instead.
